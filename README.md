Sistema de Fila de Atendimento com Padrão Iterator

Descrição 

Este projeto demonstra a aplicação do padrão de projeto Iterator em Java por meio de um sistema simples de fila de atendimento. O objetivo é permitir o percurso das senhas de atendimento sem expor diretamente a estrutura interna da fila, garantindo: baixo acoplamento, encapsulamento, separação de responsabilidades, facilidade de manutenção.
